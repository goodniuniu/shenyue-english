二、关键结论（定主线的依据）

  1. 阅读理解（含七选五）是三校最大公约数、分值第一：三卷均为"4 篇 15 题 + 七选五 5 题"结构，合计 20 题，无一校缺席。
    • 题材四件套固定：应用文/广告（牛津写作营、CVP 志愿者、科学探索挑战赛）→ 人物记叙（心理康复、野生动物教育）→ 科技/社科说明（e-Taste、AI 眼动追踪、具身认知）→ 深度议论文（技术误判、月球开发、基础科学价值）。
    • 题型分布（三卷约 60 题统计）：细节理解约 40%、推理判断约 30%、主旨要义/标题约 15%、词义猜测约 10%、写作意图约 5%。
  2. 语法与词汇是"根基线"，题量大且校校都考：语法填空 10 空三校全考，考点高度重合——真光卷答案 on / which / a / extremely / largest / construction / has faded / where / inspired / Witnessing 一行就是全部高频考点：介词、定语从句、冠词、副词、最高级、名词构词、现在完成时、从句引导词、过去分词、现在分词。
    • 执信/二中另有 20 道语法单选：强调句、名词性从句（what/that/whether）、非谓语（doing/done/to do）、倒装（Not until）、虚拟语气（It is essential that…be）、with 复合结构——正是高二上语法主干。
    • 单词拼写 + 完成句子共 66 题：词汇量是月考另一半生命线，高频词如 efficiency / absence / accompany / appetite / anxiety / resist。
  3. 写作线：应用文三校全考，读后续写仅真光考：应用文文体为报道、请求邮件、课前展示稿——都是"介绍 + 观点"结构，可模板化；读后续写在高二月考中尚未普及（新高考题型，高三比重上升）。→ 机动线优先应用文，读后续写入语料库长线积累。
  4. 完形填空三校同构：15 题，全部是记叙文 + 情感线（空难儿童求生、口吃女孩朗诵、青年治理垃圾）。考的是"故事逻辑 + 词义辨析 + 固定搭配"，不是难题，是词汇线的应用场景。
  5. 语篇话题偏好极其鲜明：语法填空三篇分别是故宫、坎儿井、华为鸿蒙——"中国文化自信 + 中国科技自立"是广州月考的心头好；阅读另一高频话题是环境保护（绿色屋顶、matrix 花园）与科技伦理。→ 词汇表与作文语料库按这四大主题建。

三、修订后的月考备考主线假设

第一主线 = 阅读理解（四选一四大题型通法 + 七选五逻辑衔接法）——分值最大、三校全考、可方法化提速。 根基线（每日固定动作）= 词汇滚动 + 语法填空考点——20 分钟/天，覆盖拼写/完成句子 66 题题量。 机动线 = 应用文写作（三校全考、模板化最快）；读后续写按真光模式备考，语料库持续积累。 原默认主线"阅读 + 读后续写"中的读后续写降为语料库长线任务（依据：仅 1/3 学校考）。
