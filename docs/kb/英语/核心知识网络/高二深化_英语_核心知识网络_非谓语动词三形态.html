【非谓语动词三形态】doing · done · to do 的「一字之差」

字段 内容
来源 人教版选择性必修一；2025.10 真光卷语法填空第 1/9/10 空（show/inspired/Witnessing）、执信卷单选 5/6/7/10 题、二中卷单选 2/8 题
时间标签 #高二深化
难度 ★★★☆☆
状态 ❌未理解

核心内容

判定总公式（先判断"句中位置"，再选形态）

句中已有谓语动词 → 闯进来的动词必须"变形"（非谓语）
 ├─ 主动/进行/功能（修饰名词、作主语宾语）→ doing
 ├─ 被动/完成/情绪形容词（人感到……）    → done
 └─ 目的/将来/特定搭配（plan to / be said to）→ to do

三大高频场景（月考 90% 考点）

场景 判断信号 真题原型
后置定语 名词 + ___：名词与动词是主动→doing；被动→done cultural relics and photos on show（真光）；the conflict broken out between the two nations（二中单选 2：which broke out / broken out 辨析）
状语（表原因/时间/结果） 句首/句尾逗号隔开：逻辑主语主动→doing；被动→done Witnessing China's history, it has...（真光第 10 空）；Convinced of the importance, more people...（执信语法填空）
with 复合结构 & 独立主格 with + 名词 + ___：主动 doing / 被动 done / 将来 to do some measuring over 90 meters（执信单选 10）

必背固定搭配（搭配优先于逻辑）

  • 只接 doing：enjoy / finish / mind / practice / suggest / avoid / look forward to / be devoted to / be worth
  • 只接 to do：plan / refuse / afford / determine / pretend / be said / be reported
  • 既可 doing 又可 to do（意思变）：remember/forget/stop/regret/try/mean
  • 感官动词 + 宾语 + do（过程）/ doing（进行）：see him cross / crossing the street

动名词做主语 vs 不定式做主语

  • 泛指一般行为 → Doing sth.（Living in a foreign country requires adaptation，执信单选 5 选 Living）
  • 具体某次/将来 → to do；It is + adj. + to do 固定句型

🗣️ 费曼讲解（讲给零基础的人听）

一个英语句子像一辆车，只能有一个司机（谓语动词）。如果又冒出一个动词想上车，它必须坐到"乘客座"变形：它如果是自己主动干的事，就变成 doing（正在进行的样子）；如果是被别人干的，就变成 done（被动的样子）；如果只是表达"要去干"（目的），就变成 to do。真光卷那题 "______ (witness) China's history, it has shaped..."——主语"它"（故宫）是"见证历史"的主动方，所以用 Witnessing。记住口诀：找到司机，再看乘客跟主语谁主动谁被动。

📝 解题示范（一道典型题完整流程）

题（真光卷语法填空原型）：With more than 450 cultural relics and historical photos ______ (show), the exhibition brings history to life.

  1. 主句谓语是 brings → show 必须变形，位置在"名词 + ___"（后置定语）。
  2. 判断关系：photos 与 show 之间——照片是被展示的 → 被动 → shown。
  3. 原卷答案为 "on show"（词组 on show = 在展出）或 shown 均可；考试遇到先答被动 done 形态。
  4. 检验：换成定语从句 "photos which were shown" 语义一致 ✅

✅ 复盘要点（自测清单，能讲清即打勾）

  • [ ] 能默写"找司机→看主动被动→选 doing/done/to do"三步
  • [ ] 能背出"只接 doing"和"只接 to do"各至少 5 个动词
  • [ ] 看到 with + 名词 + ___ 能立即分主动/被动/将来三选一
  • [ ] 真光卷 Witnessing 一题能讲清"故宫主动见证历史"的判断链
