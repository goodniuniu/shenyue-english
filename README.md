# 申悦学习 · AI 指导英语学习

从中秋假期（2026.9.25–27）备战高二第一次月考开始，用结构化知识库陪伴申悦到 2028 年高考的英语学习项目。

**运作模式**：每逢长假设计一期"专项复习计划"（诊断→主攻→模拟→复盘），平时用知识库做常态化碎片复习（每日词汇 20 分钟 + 一篇限时阅读 + 句型仿写）。专项没用完的卡片和真题回流储备池，下期直接调用。

**当前主线**（依据三校真题分析，见知识库）：**阅读理解（含七选五）第一主线 + 词汇语法根基线 + 应用文写作机动线**。

## 网站内容（发布到 GitHub Pages）

- **首页**：项目导览与时间线
- **中秋 3 天英语辅导计划**：真光卷摸底 → 阅读主线突破 + 应用文机动 → 二中卷限时模拟与错题复盘
- **长假专项复习设计框架**：小长假/长假专项的通用设计模板（日拱四件 + 3天/7天模板），国庆专项将按此生成
- **家长英语速成指南 · 阅读与写作篇**：写给多年没碰英语的家长（三问批改法 / 两轮听写 / 三眼看稿）
- **英语知识库**：语法三大件 3 卡 + 题型方法 4 卡 + 易错 2 卡 + 概念检验 30 问 + 三校真题分析报告 + 作文语料库 2 份 + 四大主题词汇表
- **卡片结构**：每张卡 = 核心内容（学）+ 费曼讲解（讲）+ 解题示范（练）+ 复盘要点（复盘），每页可一键打印，适合碎片化复习

```
家长支持/家长英语速成指南_阅读与写作篇.md # 网站内容源：家长指南（主线板块篇）
知识库/                               # 网站内容源：全部知识卡片（Markdown，常态化资源储备）
知识库/英语/素材与拓展/真题试卷/        # 2025.10 广州三校月考真题原卷+解析 PDF（含提取文本）
知识库/英语/素材与拓展/作文语料库/      # 应用文句库 + 读后续写句库（只增不减）
知识库/英语/素材与拓展/词汇/            # 四大主题高频词汇表（只增不减）
build_site.py                        # 构建脚本：Markdown -> docs/ 静态网站
build_print_pack.py                  # 打印包生成：知识卡 -> 打印包/中秋打印包_英语.pdf

package.json                         # 本地预览：npm run dev
```

## 日常维护（每次更新内容只需三步）

1. 修改对应的 Markdown 文件（或直接让 AI 把错题"入库英语"——错因自动按词汇型/语法型/逻辑型分流）
2. 运行 `python build_site.py` 重新生成 `docs/`（改了卡片后可再跑 `python build_print_pack.py` 更新打印包）
3. 提交并推送到 GitHub，网站自动更新
